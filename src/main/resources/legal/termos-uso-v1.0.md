# Termos de Uso — versão 1.0

## 1. Finalidade

Esta plataforma acadêmica demonstra operações de uma API para catálogo, estoque, pedidos, benefícios e pagamentos simulados da rede fictícia Raízes do Nordeste.

## 2. Conta e credenciais

O usuário deve fornecer informações corretas, manter sua credencial sob controle e não utilizar a conta de terceiros. As permissões dependem do perfil e do vínculo com os recursos da aplicação.

## 3. Operações simuladas

Pedidos, pagamentos, estornos, pontos, campanhas e cupons não representam transações comerciais ou financeiras reais. Os dados existem para demonstração e avaliação acadêmica do sistema.

## 4. Programa de fidelidade

O uso de pontos é facultativo e observa regras próprias de saldo, consentimento, resgate e compensação descritas pela aplicação.

## 5. Uso permitido

É proibido tentar acessar dados de terceiros, contornar controles de autorização, explorar falhas ou utilizar a API para finalidade incompatível com o projeto acadêmico.

## 6. Privacidade

O tratamento de dados é apresentado no Aviso de Privacidade vigente, publicado separadamente pela API. Consentimentos opcionais não são incorporados a estes termos.

## 7. Atualizações e encerramento

Alterações relevantes geram uma nova versão e podem exigir novo aceite para a continuidade das operações autenticadas. O usuário pode solicitar a anonimização da própria conta, observadas as limitações de preservação dos registros históricos.
